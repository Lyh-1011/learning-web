  • style.css 只管样子。改颜色只打开它。
  • script.js 只管行为。地址栏那一行是它填上的。

九步路线

  1. 浏览器打开磁盘上的一个文件。
  2. 看清路径：文件在哪，浏览器从哪把它拿出来。
  3. 把页面拆成结构、样式、行为。
  4. 用 Git 给这一页留下可以回退的存档。
  5. 把本地存档同步到 GitHub。
  6. 把静态网页放到公网上，让别人也能打开。当前在这里。
  7. 页面变大、难维护之后，再引入现代前端。
  8. 要做功能时，补上 API 和后端。
  9. 数据要留下来：先文件，再数据库，再认出同一个人。

这一步带走

  • GitHub 保存代码与版本记录，服务器运行网页服务。
  • 这台服务器上的 Caddy 接收浏览器的请求，按域名找到网站，再返回网页文件或转交给后端程序。
  • 本地 commit 保存版本，push 推送到 GitHub；服务器每分钟自动检查 main，拉取并发布有变化的网页文件。
